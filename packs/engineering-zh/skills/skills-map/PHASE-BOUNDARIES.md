# 阶段边界：继续、开新会话、交接、派子代理

一块工作到达收工标志、下一块还没动手时，读这一页，从四个选项里挑一个。技能选型看同目录 `SKILL.md` 的路由表；这一页只管会话与执行单元的边界。

选错的代价是单向的：上下文被无关材料稀释之后收不回来，交接漏掉的理由补不回来。

## 一、认准判断的那一刻

- 在收工标志出现时才判断：测试全绿、票据状态推进一格、一轮问题问完、一份审阅结论交出去。
- 判断完立刻执行，不在对话中途换执行单元——中途换会丢掉正在累积的共识。
- 每次判断交出一句话：「选 X，因为 Y」，Y 引用下面某一节的可观察信号。
- 完成标准：用户能读到这句判断和它的依据，而不是只看到你换了会话。

## 二、按顺序排除，四个选项

按下面的顺序走，第一个成立的就是答案：

1. **量上下文余量**（第三节）。还宽裕就往下走；已过舒适区，「继续」这一项直接划掉。
2. **测自包含**（第四节）。自包含 → 派子代理，用 `subagent` 工具。
3. **测是否离开本机、离开当前的人**（第五节）。要离开 → 交接。
4. **其余情况 → 开新会话**，先把状态落进文件再开。
5. 只有上下文宽裕、且下一步要反复与用户对齐口头共识时，才选**继续当前会话**。

## 三、先排除「继续」，再排除别的

「继续」是默认选项，不需要任何动作，所以最容易被误用。给它加一道举证责任：能说出「新会话要重读哪些文件、大概多少行」，才选继续。

**已过舒适区的信号**（出现两条以上就划掉继续）：

- 需要往上翻才能记起某个决定、某个函数名、某个数字；
- 同一件事实在同一段回答里被复述第二遍；
- 同一个文件读了两次，第二次才发现第一次漏了；
- 最近几轮几乎只有工具调用与回读，没有新的结论产生；
- 说「按之前定的」时，说不清之前定的是什么；
- 要重读用户最初那句话才能确认要求。

**还在宽裕区的信号**（直接引用而不必回查）：

- 能直接说出前面定下的名称、数字、结论；
- 上一块的产出还在手边，不需要重新读入；
- 新到的材料只占一小段，判断没有被它挤掉。

**还剩几个阶段**：数清后面还有几块要收工。剩三块以上、且每块都要重读同一批文件 → 开新会话，先落文件。只剩一块收尾、输入还在上下文里 → 继续。

## 四、这一步是否自包含：三个可判定的检查

自包含的活有三个特征，全中才可以交给子代理或放进新会话：

1. **输入可取**：输入能从一个文件、一条命令、一段引文里取到，不需要通话记录里的口头共识。
2. **产出可放**：产出能写回一个文件或一条命令的结果，不必让别人保管中间状态。
3. **中途不问**：跑完之前不需要用户中途确认。

反向信号是：要先和用户对一次口径、要沿用「我们刚才说的那个方案」、产出是一段判断而不是一个文件。

**下一步依赖多少当前上下文**：把它需要的材料列成清单，逐项标出在哪里。清单里半数以上只存在于对话历史（没进规格、票据、决策记录、代码注释）→ 先落文件，再决定继续还是开新会话；几乎都能在文件里重新读到 → 开新会话的重读成本很低，直接开。

## 五、交接只买到可携带性

交接写出一份交接文档，把状态搬到一个能带走的地方。它买到三样：可跨机器、可转交别人、可让主线与支线并行。它不压缩信息，也不省上下文——写这份文档本身要花掉接近完整的一份上下文，带过去的是它的复述。

- 想省上下文：把状态落进仓库文件（规格、票据、决策记录），再开新会话读文件。留在本机就够，不必交接。
- 想换机器、换人接手、在当前目标旁边岔一条支线：用交接。用 `skill` 工具加载 `handoff` 前先说明该用它，让用户手打 `/handoff` 发起。
- 交接文档里放一节「未决与理由」，写下还没定的分歧、被排除的做法和原因。完成标准：接手方能不改动地开工，并能说出为什么排除了别的做法。

## 六、一手材料与二手材料的有损交易

原始对话是一手材料：用户的原话、被否决的方案、失败尝试的路径、还没成形的直觉都在里面。交接文档、总结、笔记是二手材料：写的时候只能挑一部分，漏掉的部分不会有提示。

- **值得换**：结论已经写进文件、接收方只需按结论干活、任务边界清楚。
- **先别换**：还有未定的分歧、下一步会推翻当前结论、需要复现当初为什么这么选。

损失集中在理由上。把理由单独写下来，这次交易就接近无损。

## 七、决策对照表

| 处境 | 选择 | 一句话理由 |
|---|---|---|
| 同一目标只差收尾，输入还在手边 | 继续当前会话 | 重读成本高于省下的上下文 |
| 上下文宽裕，下一步要反复与用户对口径 | 继续当前会话 | 口头共识搬不进文件 |
| 目标换了一块，材料都已落进文件 | 开新会话 | 重读一遍比背着旧材料便宜 |
| 已过舒适区，后面还有三块以上要收工 | 先落文件，再开新会话 | 旧材料正在稀释新判断 |
| 历史里有没落文件的口头共识，且已过舒适区 | 先落文件，再开新会话 | 不落文件，新会话接不上 |
| 要换机器或换人接手 | 交接（`/handoff`） | 只有它能离开本机与本人 |
| 要在当前目标旁边岔一条支线，主线留着 | 交接（`/handoff`） | 支线要独立的历史，主线不能被带走 |
| 一件自包含的活：查资料、跑实验、扫一遍代码 | 派子代理（`subagent`） | 过程不必回到主上下文 |
| 下一步需要中途与用户确认 | 继续当前会话 | 中途确认跨不过执行单元边界 |
| 要同时试两条互斥方案 | 各派一个子代理 | 两条结论互不污染 |

## 八、收尾检查

判断做完，确认三条都成立：选项带一句话理由；要带走的材料已经落在文件里；下一步的输入能从文件或命令取到。
