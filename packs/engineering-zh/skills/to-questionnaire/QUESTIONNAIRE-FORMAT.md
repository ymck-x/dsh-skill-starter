# 问卷格式与填写体验

这份附件承载问卷本身长什么样、怎么让人愿意填、答案拿回来之后落到哪。正文讲怎么盘问「发送」，这里讲交付物和后续。

## 一、完整骨架：六节，顺序不变

每节都写一句判据。写完一节就对着判据检查一遍，不满足就重写这一节。

1. **目的**——拿回什么、会怎么用。
   判据：两句话里必须出现一个具体决定。写成「我想了解你在 X 上的想法」不算，要写成「拿到这组数字后，我才能定下个季度的排期」。
2. **谁问的发给谁**——你的名字和角色，对方的名字和角色。
   判据：对方读到这一行能确认「这是写给我的、这是谁在问」。用角色也写清具体是哪个人接手。
3. **背景**——对方需要的最小上下文。
   判据：对方读完能直接答题，不必回头翻任何别的材料；删掉任何一句后，仍有题答不出来就说明删多了。
4. **怎么填**——预计用时、截止时间、能否只答一半、拿不准的题怎么标、填完发回哪里。
   判据：五件事都写明，尤其「能否只答一半」要有明确答复，不要留给对方猜。
5. **主题小节**——按主题分组，组内按重要性降序。
   判据：每个小节有自己的小标题，每题标出作答类型（一句话 / 选择 / 数字）和你要的粒度。
6. **还有什么要补充**——最后一道空题，让对方写下你没问到的事。
   判据：这道题独立成节，留足作答空间，且明确写「选填」。

```
# <问卷主题>

## 目的
我要做的决定是 ____。你的答案会用在 ____。

## 谁问的发给谁
问：<你的名字>（<角色>）  答：<对方名字>（<角色>）

## 背景
<三到六句最小上下文>

## 怎么填
预计 <N> 分钟。截止 <时间>。可以只答一部分，没答的题留空即可。
拿不准的题在作答处写「不确定」。填完把文件发回 <渠道/人>。

## <主题一>

### Q1 <问题>（一句话作答，20 字以内）
>
### Q2 <问题>（选择：A / B / C）
>

## <主题二>
...

## 还有什么要补充
（选填）还有哪些我没问到、但会影响这件事的信息？
>
```

## 二、问题下面留作答占位

每道题下面紧跟一行空引用块 `>` 或多行缩进空白，作为作答区：

```markdown
### Q3 上个季度的返工主要来自哪几个环节？（可写两到三条）
>
```

为什么必须留：对方要能直接在这个文件里填完发回，不必另开文档、另写邮件。占位行同时告诉他「答案写在这里」，省掉一轮来回。

## 三、怎么写出好问题

- **一题只问一件事**。「你们的排期紧张吗，主要卡在哪」拆成两题，否则对方只会答好答的那半。
- **能选就别让人写**。给两到四个互斥选项，加一个「其他」，让对方勾选而不是组织语言。
- **必须开放回答时给方向和长度**。写清「一句话」「三条以内」「带单位和量级」，把回答的形状先画出来。

判据：拿一道题去问自己「对方能不能一句话答完」。不能，就是题目没写清。

## 四、填写体验

- **预计用时要诚实**。按每题一分钟估，写完实际试答一遍，把真实数字写进「怎么填」。
- **示例答案能降低门槛**。在难答的题下面加一行灰字示例，说明你期待的格式和粒度。
- **题量控制在 5 到 12 题**。少于 5 题通常一次性问完就够，不必发问卷；多于 12 题，按主题拆成两份，各自独立发送。
- **让对方可以只答一半**。给「留空即可」的许可，比逼他答完更能保住前面几道关键题的回收率。

## 五、怎么排顺序

按重要性降序排，最缺的那道放主题小节的第一位。

异步填写通常只有一次机会：对方可能在通勤路上、会议间隙打开这份问卷，填到一半就被打断，之后再没回来。你拿到的是前几题。因此排在前面的必须是你最缺的答案，把「锦上添花」的题往后放。

## 六、文件名与存放位置

```
docs/agents/questionnaires/<YYYY-MM-DD>-<主题短名>.md
```

- `<主题短名>` 用问卷主题本身，小写加连字符，例如 `2025-03-14-q2-release-scope.md`。
- 文件名与文件内一级标题保持一致，方便对方在聊天记录里搜到。
- 同一主题的第二轮问卷用新日期重开一份，把上一份的路径写进「背景」节，形成追溯。

## 七、回收之后怎么用

拿到答复后立刻把它变成下游产物，不要让答案停在文件里：

- **答案补上了信息缺口**——把结论写进对应的规格（spec）或票据的「背景」节，附上问卷路径作为依据。
- **答案推翻了一个已有判断**——按 `domain-modeling` 技能记一份决策记录，写清决定、理由和这份问卷的路径。
- **答案带来新的缺口**——直接发起第二轮问卷，只问新增的题，并在「背景」里引用上一份。

答案不完整时的处理：

1. 先判定缺的是哪几题，看它们是否落在「排在前面的最缺答案」里。
2. 关键题缺了，按新缺口补一轮，只问这几题，题量压到 1 到 3 题。
3. 关键题齐了、只缺次要题，就用现有答案推进，把缺失项记成一项待确认风险，不要为它再发一轮。

完成标准：每份问卷在答复回收后，都能指向一个具体的下游产物（规格、决策记录或下一轮问卷）。
